The single funniest word an agent says when it has no idea what to do — "Welp": the verbal shrug, the exact sound a chatty agent blurts the moment it realises it is stuck. Chosen by a 20-candidate criteria screen and a full 28-pair round-robin tournament (7–0, undefeated) over Uh-oh, IDK, Mayday, Dunno, Nope, Yikes and SOS. See CANDIDATES.md in the build notes for the full tournament.

`main.py` (standard library only, deterministic) writes the 4-character word to `$MAKEFUN_OUTPUT_DIR/entry.txt`.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=/tmp/out python3 main.py
cat /tmp/out/entry.txt
```
